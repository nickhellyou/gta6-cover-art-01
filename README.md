Neon Coast Cover Studio turns your photos and a caption into GTA 6-style cover art in the browser: six multi-panel poster layouts, five Vice City sunset and neon colour grades, bold Anton lettering with a sunset gradient fill and a Pacifico script subtitle, a badge ribbon, halftone title band, film grain and vignette — then exports a PNG in 1080 x 1080, 1080 x 1350 or 1920 x 1080. It runs offline from its own static files; photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
